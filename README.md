# SonoLune

**Screen dimmer, blue light filter and ambient sound — for the whole phone.**

[Get it on Google Play](https://play.google.com/store/apps/details?id=com.soundsoftlab.sonolune) ·
[sonolune.app](https://sonolune.app)

Most of these things exist as separate apps, and that is the problem. A dimmer that does not
know the filter is on. A sound app that keeps playing while you are trying to sleep. Seven
things competing, each one certain it is the important one.

SonoLune runs them as one. Light, sound, focus and schedule know about each other, so the phone
settles instead of negotiating with itself.

## What is in it

| Suite | What it does |
|---|---|
| **Light** | Warmth along a colour-temperature curve, blue reduction, dimming below the panel's own minimum, paper-matte grain, and veils that reach system UI |
| **Sound** | Layered ambient atmospheres — elements, micro textures, binaural depth — and sessions you can download |
| **Focus** | A named intention, a room, matched light and sound, optional breathing, and an end that does not congratulate you |
| **Mind** | Suggested moments and reflections, tuned to the time of day |
| **Presence Field** | Per-app calm, applied as a field rather than a block list |
| **Lunar Arc** | Wake, Focus, Sound, Light, Mind, Reminder and Night placed across the day |
| **Night** | Moon, stars and haze for late hours, with arrival timing you set |

## What it does not do

No account. No ads. No analytics, no profiles, no data collection — nothing leaves the device.
It works fully offline, including the parts that look like they should need a server.

No streaks either, and that is deliberate. An app about calm has no business keeping score.
