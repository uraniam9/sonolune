# SonoLune 1.6.2

**Night badge and guided Arc polish** · 29 May 2026

A focused polish release for scheduled Night entry, held-field behavior, Focus Arc timing, free Night Arc access, Focus Eye Rest, Lune Guard Breath Cue, and refreshed guide pages.

## Highlights

- Night is waiting badge now taps reliably into Night Environment
- Night badge copy no longer shows an unwanted underline
- Entering Night now preserves the held Mind Suite field instead of resuming it
- Night notifications can show Night Environment while the actual field remains held
- Night Arc is now available to free users with a default Night window
- Custom Night Arc timing remains a Supporter unlock
- Focus Arc now shows the custom duration slider to free users as a locked Supporter control
- Lune Guard outside cues now rotate with longer time-aware eye-rest guidance
- Longer Lune Guard resets and custom break rhythms now sit behind the Supporter gate
- Breath Cue now has Supporter shaping with live preview, cue tools, countdown, and rhythm shortcut
- Focus now integrates Lune Guard Eye Rest for longer sessions
- Eye Rest uses a Breath Cue after 20 active Focus minutes in sessions of 25 minutes or more
- Focus completion can now note when the user’s eyes were held during the session
- Lune Guard now includes a Breath Cue Fieldbook so users can practice the same resets that appear outside SonoLune
- Outside Breath Cue names now align with Lune Guard exercises such as Far Field, Blink Wave, Near Far, Eye Orbit, Palm Dark, and Soft Return
- Sound Atmosphere stereo width now explains that Neuro Layers must be selected first

## Night Environment

- Fixed the Night is waiting badge so tapping it routes into Night Environment instead of doing nothing from the existing Night page.
- Removed the unwanted yellow underline from the Night badge label.
- Night badge routing now refreshes same-page Night entry safely, so the badge can be consumed even when the user is already on the Night tab.
- Entering Night no longer clears the suspended Mind Suite field.
- Night notification summary can present Night Environment while the real held field remains suspended until the user returns it from Mind Suite.

## Lunar Arc

- Night Arc is now accessible to free users through a default 10:30 PM to 6:30 AM Night window.
- Custom Night Arc start time, end time, and descent shaping remain Supporter-only.
- Free Night Arc saves are sanitized to the default Night window so older custom drafts cannot bypass the intended gate.
- Focus Arc now keeps the custom duration slider visible for free users as a locked Supporter control.
- Tapping the locked custom Focus Arc slider opens the custom focus duration support gate instead of hiding the feature.

## Lune Guard

- Outside-SonoLune Lune Guard cues now rotate by time of day.
- Outside Breath Cues now use the same exercise language as Lune Guard, including Far Field, Blink Wave, Near Far, Eye Orbit, Neck Drift, Palm Dark, and Soft Return.
- Morning cues include window distance, near/far rounds, and horizon scanning.
- Daytime cues include 20-20-20 field, desk reset, four-corner gaze, and standing distance breaks.
- Evening and night cues now soften into palming, distance breathing, low night gaze, and dark rest.
- Cue durations now extend beyond the old short 15 to 30 second pattern for more useful eye-rest breaks.
- Longer eye resets and custom outside break rhythms now correctly open the Lune Guard Supporter gate, while the base 20 second reset and 20 minute rhythm remain free.
- Breath Cue now identifies itself as SonoLune Lune Guard, uses a collapsed Cue tools shortcut, and shows a countdown so the user knows when it will fade.
- Supporters can shape Breath Cue with live preview, color scheme, screen position, type style, transparency tone, card size, and appear time.
- Tune rhythm now opens Lune Guard directly to the cue rhythm controls so the outside reset can be adjusted later.
- Breath Cue Fieldbook now gives the exercise cards a clear home so users can practice inside Lune Guard before the cues appear outside SonoLune.

## Focus and Eye Rest

- Focus Session now has a Lune Guard Eye Rest option for longer sessions.
- Eye Rest is available for Focus sessions of 25 minutes or more, with a Breath Cue after 20 active Focus minutes so it does not collide with the ending ramp.
- Pausing Focus also pauses Eye Rest timing, so cues follow active Focus time rather than wall-clock time.
- The Focus setup card now links to Lune Guard so users can shape Eye Rest before starting; route changes remain blocked while Focus is active.
- Focus completion can now gently say that the user’s eyes were held once during the session.

## Sound Atmosphere

- Stereo Width now guides the user to select a Neuro Layer before shaping spatial width, instead of feeling inactive.

## Guides

- Updated the Environment Guide to reflect current Light Suite, Sound Atmosphere, Mind Suite, Focus, Night, Lune Guard, Lune Field, and Lunar Arc behavior.
- Updated the Future of SonoLune page around the whole-field direction, Soundsoft Lab Sessions, Lune Guard, Lunar Arc, and supporter philosophy.
- Updated the Experiments page with current Labs language for Mind Programmer Whispers, Moment Memory, optional light coverage, and Soundsoft Lab groundwork.
