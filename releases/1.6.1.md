# SonoLune 1.6.1

**Arc handoffs and Sound Atmosphere welcome** · 27 May 2026

A focused refinement release for Lunar Arc reliability, Sound Atmosphere onboarding, Focus light clarity, Mind Arc flow, and smoother update prompts.

## Highlights

- Sound Arc now opens the exact Sound Atmosphere preset that fired
- Mind Arc notifications now land on the exact queued Space, Living, Focus, or care moment
- Mind Arc selected moments now show queue order numbers
- Sound Atmosphere gained a first-run picker for choosing a starting field
- Focus Calm Light now shows the selected light preset on its chip
- Arcs now respect the held Mind Suite field before changing light, sound, or mind state
- Night is waiting now clears when the user enters Night manually
- Lune Guard breath cues now show fuller eye-rest guidance outside SonoLune
- Soundsoft Lab Sessions are easier to understand inside Sound Atmosphere
- Update prompts now include update, changelog, and skip-for-now actions

## Lunar Arc

- Sound Arc now prepares the scheduled Sound Atmosphere field silently, then plays the full field when tapped.
- Sound Arc notifications now name the selected soundscape before opening it.
- Mind Arc now opens the exact queued moment that fired, including Space, Living, Suggested Focus, and Lune Guard moments.
- Queued Mind Arc notifications feel steadier when SonoLune is already open.
- Light, Sound, and Mind Arcs now respect a held Mind Suite field before changing state.
- Scheduled Arc fire-time handling and notification tap handling now both preserve the held field.

## Mind Arc

- Mind Arc moment chips now show queue order numbers so the user can see the firing order before saving.
- Single-moment Mind Arc timing now reads as a Mind Arc window instead of a total queue length.
- Multi-moment queues keep the total queue length explanation because the duration is divided across selected moments.
- Focus moments now stand alone, while Space, Living, and Lune Guard can queue cleanly across the Mind Arc window.
- Held-field guidance now includes a clear Mind Suite return action.

## Sound Atmosphere

- Added a first-run Sound Atmosphere picker with Quiet Focus, Rain Drift, Living Canopy, Deep Rest, and Quiet Room.
- The first-run picker now fits smaller screens without bottom overflow.
- Saved custom soundscapes now stay highlighted only while that exact saved field is active.
- Tweaking a saved soundscape now correctly turns it into a shaped custom field instead of keeping the saved preset selected.
- Soundsoft Lab Sessions now explain future downloadable ambience more clearly.
- Supporter copy around saved soundscapes and deeper sound fields is calmer and easier to understand.

## Focus Session

- Calm Light now shows the selected Focus light preset on its chip instead of a static Color Veil label.
- Ambient Field now prefers friendly preset names such as Soft Rain, Gentle Focus, and Distant Ocean before showing a custom composition.
- Focus light choices continue to persist through navigation and cold start as part of the saved Focus environment.

## Night and Lune Guard

- Night is waiting now hides as soon as the user enters Night manually, so the badge never lingers over an active Night field.
- Night badge entry uses the app router directly for steadier foreground navigation from any SonoLune screen.
- Outside-SonoLune Lune Guard breath cues now show the practical eye-rest instruction, not only a short hint.
- Lune Guard cues stay visible longer and remain understandable even when Quiet Return notifications are turned off.

## Polish

- Fixed the Share Your Field poster moon rendering so the moon no longer shows a hard square edge.
- Improved update prompt behavior with update, changelog, and skip-for-now actions.
- Restored visible version numbers in the Field Journal while keeping internal build numbers hidden.
- Release notes now read more naturally for everyday users.
