# SonoLune 1.3.1

**The most stable update yet** · 12 Apr 2026

A broad refinement release that deepened sound, clarified navigation, improved persistence, and resolved a series of environment bugs.

## Highlights

- Four new Sound Atmosphere soundscapes
- Adaptive notification summaries
- Named compositions
- Persistent sound state across restarts

## What's New

- Four new Sound Atmosphere soundscapes joined the ambient field.
- Adaptive notification summaries now unify ambient field status inside Mind Suite with one label and one truth.
- Named compositions now title your built sound sessions with names like Forest Rain, Shore Ember, and Neural Pulse.
- Sound positions, Neuro Layers, volumes, stereo width, and drift time now persist faithfully across restarts.
- Redesigned navigation now breathes with the ambient color of your current field.

## Full Changelog

- Onboarding content updated with the latest version enhancements.
- Support page redesigned with context-aware permission gates and helper texts.
- Mind Suite UI polish and UX improvements throughout.
- Sound Atmosphere UX drastically improved with significant fixes.
- Night presets and soundscapes now keep active soundscape positions across restarts.
- Moments now preserve expanded state and active moment position across restarts.
- Focus Session start now displays the anchor text in the card.
- Focus Session completion now shows total subliminals flashed, with session summaries.
- Notification summary fixed after appearing only once light permission had been granted.
- Moments locking issue fixed.
- Environment suspend mode fixed.
- Sacred Night Mode toggle and preset mapping fixed in Night Environment.
- Sound and permission gate bypass leaks fixed.
- Overall performance improvements and bug fixes across all of SonoLune.
- The entire user experience was refined further.
